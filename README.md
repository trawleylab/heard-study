## Changing anything here

The QR code on the printed poster encodes the URL above, not any particular file.
The page can therefore be edited freely — adding the DOI once the paper is published,
for instance — without reprinting the poster. Two things must not change:

- the repo name, and
- the GitHub Pages setting (deploy from `main`, root folder).

Either would break every printed QR code.

If `poster_879.pdf` is regenerated, replace it here under the same filename so the
download link on the page keeps working.

## Provenance

Every figure on the poster and this page traces to the Health Expectations submission
of 29 July 2026 — the main document, Tables 1–3 and Supplementary Tables S1–S2.

Note that the congress abstract was submitted on an earlier analysis (877 responses
analysed) and these figures come from the final one (856). Theme percentages differ
and the rank order of themes 2 to 5 changed. The poster carries a footer line saying
so. If anyone compares the poster against the abstract book, that is the explanation.

The two participant quotes are reproduced verbatim from the coded response file
(`HEARD_All_Responses_Coded.xlsx`, rows 8 and 71); only the apostrophes were curled
for print.

Language throughout follows the Diabetes Australia *Our Language Matters* position
statement (2021).
